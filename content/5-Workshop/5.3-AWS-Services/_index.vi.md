Campus IT Support Ticket Portal sử dụng nhiều dịch vụ AWS được quản lý để xây dựng một kiến trúc serverless hoàn chỉnh.

Mỗi dịch vụ đảm nhận một vai trò riêng, bao gồm lưu trữ frontend, xác thực người dùng, quản lý API, xử lý nghiệp vụ, lưu trữ dữ liệu, gửi email, giám sát và kiểm soát quyền truy cập.

Các phần tiếp theo sẽ trình bày cách từng dịch vụ AWS được sử dụng trong dự án:

- AWS Amplify Hosting
- Amazon Cognito
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- Amazon SES
- Amazon CloudWatch
- AWS IAM

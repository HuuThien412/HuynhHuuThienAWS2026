# AWS Services

The Campus IT Support Ticket Portal uses a collection of managed AWS services to implement a complete serverless architecture.

Each service performs a specific responsibility, including frontend hosting, authentication, API management, business logic, data storage, email delivery, monitoring, and access control.

The following sections describe how each AWS service is used in the project:

- AWS Amplify Hosting
- Amazon Cognito
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- Amazon SES
- Amazon CloudWatch
- AWS IAM
